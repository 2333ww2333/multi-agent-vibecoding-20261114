# 外部调研 SOP

## 何时用
需要从互联网获取事实、对比多个说法、或引用官方文档时。

## 步骤
1. **明确问题**：先用一句话写下「要回答的确切问题」和「判定标准」。
2. **优先官方源**：语言/框架官方文档 > 官方博客 > 可信技术媒体 > 论坛。
3. **至少两个来源**：单一来源的结论标注「未交叉验证」。
4. **记录出处**：每条结论后面必须有 URL，格式 `（来源：https://...）`。
5. **区分事实与推断**：推断必须写「推断：」前缀。
6. **给不确定项**：明确列出「没查到的」「说法冲突的」。

## 输出格式

回禀固定四段（用二级标题开头）：

- `## 结论`：1~3 句话直接回答。
- `## 依据`：每条事实一行，结尾必须带 `（来源：URL）`。
- `## 不确定 / 冲突`：没查到的、说法矛盾的，都列在这里。
- `## 建议下一步`：可选，最多 3 条。

## 禁止
- 编造 URL。
- 把博客观点当官方结论。
- 省略出处。
